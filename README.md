# Финни — игра о личном бюджете для детей 7–11 лет

Прототип мобильного приложения для Android. Ребёнок заводит питомца, получает
игровые монеты, раскладывает их на обязательное, желаемое и копилку, выполняет
задания и видит, как его решения меняют состояние питомца.

Решение задачи 6 трека «Финансы» хакатона ЛЦТ 2026. Заказчик — Департамент
финансов города Москвы.

> ⚠️ Промежуточная сдача, {ДАТА}. Что реализовано, а что нет — в
> [матрице требований](docs/requirements-matrix.md).
