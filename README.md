# Финни

Игра для Android, в которой ребёнок 7–11 лет заботится о питомце Финни и учится
обращаться с деньгами. Каждую игровую неделю приходит доход в монетах. Ребёнок
раскладывает его на три направления — «Нужное», «Хочу», «Копилка», — покупает еду и
мыло, копит на подарок, а в конце недели видит, что задумал и что вышло. Без оценок:
приложение называет факты и никогда не говорит, что выбор был неверным.

Решение задачи 6 трека «Финансы» хакатона ЛЦТ 2026.

## Сборка и запуск

Нужны JDK 17 или новее (подходит встроенная в Android Studio) и Android SDK с
платформой 36. Проще всего открыть папку проекта в Android Studio и нажать Run.

Из терминала:

```bash
./gradlew :app:assemblePrototype   # оптимизированная сборка: app/build/outputs/apk/prototype/
./gradlew :app:assembleDebug       # отладочная сборка
```

Сборка `prototype` оптимизирована как выпускная и подписана отладочным ключом — её
можно установить на любой телефон без среды разработки.

## Проверка

```bash
./gradlew :core:test               # экономика недели, правила, тексты
./gradlew :app:testDebugUnitTest   # экраны на JVM и автоматический прогон «как ребёнок»
./gradlew :app:recordRoborazziDebug  # снимки экранов 360 dp, шрифт ×1 и ×2 → app/build/shots/
```

Автоматический прогон «как ребёнок» 80 раз по 300 шагов случайно нажимает всё, что
нажимается, и после каждого шага проверяет: деньги не уходят в минус, числа на экране не
больше 100, фразы не длиннее 5 слов, экран не длиннее 25 слов, цели нажатия не меньше
48 dp. Отчёт — `app/build/qa/monkey-report.md`.

## Устройство

| Модуль | Что внутри |
|---|---|
| `core` | правила игры без Android: модель состояния, ходы недели, расчёты, тексты из состояния. Тестируется на JVM |
| `core/src/main/resources/content/` | контент отдельно от кода: предметы и цены, недели и задания, все тексты игры |
| `app` | интерфейс на Compose, хранение, питомец и анимации |

Экраны ничего не считают сами: каждое действие — ход в правилах `core`, состояние
сохраняется после каждого хода. Новое задание или предмет добавляется в файлы контента.

## Что реализовано

Глава 1 целиком, две игровые недели:

- знакомство с тремя направлениями, создание питомца — 3 окраса × 3 аксессуара, имя;
- выбор одной из трёх целей накопления;
- главный экран: питомец, кошелёк, накопления, цель, показатели «сыт», «чист», «тепло»,
  активное задание;
- доход посылкой и план на неделю по трём направлениям — с остатком и превышением;
- магазин: обязательные и необязательные покупки, цена, категория и влияние на питомца до
  покупки, нехватка денег в направлении с понятными вариантами, снятие из копилки с
  отдельным подтверждением;
- копилка с прогрессом к цели и расчётом, хватит ли к событию;
- задания «Что взять на неделю» и «Мячик сейчас или подарок потом», объяснение после
  каждого действия;
- итог недели: план против факта, откуда взялась разница;
- событие главы с двумя исходами, свободная игра;
- сохранение между запусками, крупный системный шрифт, подписи для экранного диктора,
  отключение анимаций системной настройкой Android.

Графика — временная, нарисована кодом.
