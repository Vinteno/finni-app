# Финни

Игра для Android, в которой ребёнок 7–11 лет заботится о питомце Финни и учится обращаться с
деньгами. Каждую игровую неделю приходит доход в монетах. Ребёнок раскладывает его на три
направления — «Нужное», «Хочу», «Копилка», — покупает нужное на неделю, выбирает между вещью и
вещью с надбавкой, копит на цель главы, а в конце недели видит, что задумал и что вышло. Без
оценок: приложение называет факты и никогда не говорит, что выбор был неверным.

Решение задачи 6 трека «Финансы» хакатона ЛЦТ 2026.

данные, аккаунт не требуется.

## Как поставить APK

1. Скачать `apk/finni-0.3.2.apk` на телефон с Android 8.0 или новее.
2. Открыть файл и разрешить установку из этого источника, если телефон спросит.
3. Запустить «Финни».

Файл `apk/finni-0.3.2.apk` собран как `release` и подписан постоянным ключом команды. Он устанавливается
без среды разработки. SHA-256 и сведения о подписи приведены в [`docs/submission.md`](docs/submission.md).

## Локальный запуск из исходников

Нужны Android Studio со встроенным JDK 17+ и Android SDK Platform 36. В SDK Manager должны быть
установлены Android SDK Platform 36, Build-Tools 36 и Platform-Tools; команда `adb` из Platform-Tools
должна быть доступна в `PATH`. Сервер, база данных и `.env` не нужны: приложение полностью локальное.

### Android Studio

1. Клонировать репозиторий и открыть его корневую папку, где лежит `settings.gradle.kts`:

   ```bash
   git clone https://github.com/Vinteno/finni-app.git
   cd finni-app
   ```

2. В Android Studio выбрать встроенный Gradle JDK и дождаться синхронизации проекта.
3. Создать эмулятор с Android 8.0 (API 26) или новее либо подключить Android-телефон с включённой
   USB-отладкой. Ориентация — портретная, ширина экрана — от 360 dp.
4. Выбрать конфигурацию `app` и нажать Run. При первом запуске Gradle скачает зависимости.

Android Studio сама создаёт локальный `local.properties` с путём к SDK. Этот файл не коммитится.
Если синхронизация сообщает, что SDK не найден, нужно открыть SDK Manager, установить платформу 36
и повторить синхронизацию.

### Терминал

Запускать команды из корня репозитория. На Windows вместо `./gradlew` используется `gradlew.bat`.

```bash
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Оптимизированная сборка для демонстрации:

```bash
./gradlew :app:assemblePrototype
adb install -r app/build/outputs/apk/prototype/app-prototype.apk
```

Обе сборки подписаны отладочным ключом текущего компьютера. Если устройство сообщает
`INSTALL_FAILED_UPDATE_INCOMPATIBLE`, на нём уже установлена сборка с другим ключом. Её нужно удалить
перед установкой; это удалит локальный прогресс:

```bash
adb uninstall ru.vinteno.finni
```

## Проверка

```bash
./gradlew :core:test               # правила: экономика восьми недель и прогон стратегий, главы, задания, нормы текста
./gradlew :app:testDebugUnitTest   # экраны на JVM, сквозные прогоны и «ребёнок»
./gradlew :app:recordRoborazziDebug  # снимки экранов 360 dp, шрифт ×1 и ×2 → app/build/shots/
```

«Ребёнок» — 80 партий по 300 случайных касаний по всем трём главам; после каждого шага проверяет:
деньги не уходят в минус и не исчезают при накоплении, фразы не длиннее 5 слов, экран не длиннее
25 слов, цели нажатия не меньше 48 dp. Подробно — [`docs/testing.md`](docs/testing.md).

## Демо-режим для проверки

На главном экране — плашка «Взрослым» под кошельком: **удерживать 3 секунды**. В разделе для
взрослого, блок «Демо-режим»:

- **«Начать демо»** — полный путь с предыстории, выбора внешности и имени питомца; игра ребёнка
  сохраняется отдельно;
- **«Открыть неделю или задание» 1–8** — подписанные переходы доступны сразу, даже до начала демо;
  каждый открывает начало недели с состоянием канонического пути, без ожидания;
- **«Начать демо заново»** — к предыстории исходного тестового профиля;
- **«Вернуться к игре ребёнка»** — игра ребёнка как была.

Пошаговый маршрут проверки по Приложению А — [`docs/demo-guide.md`](docs/demo-guide.md). Там же —
«Удалить данные игры» (с подтверждением), сложность «Проще / Сложнее», анимации.

## Устройство

| Модуль | Что внутри |
|---|---|
| `core` | правила игры без Android: модель состояния, ходы недели, расчёты, тексты из состояния, демо-путь. Тестируется на JVM |
| `core/src/main/resources/content/` | контент отдельно от кода: предметы и цели, главы и недели, задания, все тексты |
| `app` | интерфейс на Compose, хранение, питомец и анимации |
| `art/app` | графика: слои Финни, предметы, комнаты |

Экраны ничего не считают сами: каждое действие — ход в правилах `core`, состояние сохраняется после
каждого хода. Новое задание или предмет добавляется в файлы контента — [`docs/architecture.md`](docs/architecture.md).

## Что реализовано

Три главы, восемь игровых недель по каноническому пути (до десяти — при запасных неделях):

- **первый запуск:** предыстория с тремя направлениями, питомец — 3 окраса × 3 аксессуара, имя;
- **главный экран:** Финни, кошелёк, накопления клетками с целью, «Еда», «Чистота», «Тепло», записка
  с текущим шагом; действия — касанием предметов комнаты; касание Финни — подсказка шага;
- **неделя:** доход посылкой, объявление ситуации, план по трём направлениям с остатком и
  превышением, магазин с ценой, категорией и влиянием до покупки, корзина как подтверждение,
  окна нехватки с вариантами и снятие из копилки с отдельным подтверждением, забота дома, взнос,
  итог «Задумали / Вышло» по трём направлениям с объяснением разницы и выбором плана следующей недели;
- **ситуации глав 2 и 3:** куртка, заноза, коробка, лампа, угощение, полотенце — две равные карточки
  «вещь» и «вещь с надбавкой» с разложенной ценой;
- **шесть заданий по трём темам:** F1 «Что взять на неделю», F5 «Мячик сейчас или подарок потом»,
  F4 «Сколько отложить», F3 «Куртка уже есть», F2 «Чем заплатить», F6 «Что задумали и что вышло» —
  с объяснением после любого решения;
- **план и копилка:** три банки с цельными цветными крышками; уровень золотой россыпи показывает
  относительное количество в общем масштабе, а ярлык под каждой банкой — точное число. На экране
  плана написано «Разложи монеты». Свинка-копилка показывает путь к цели квадратами: один квадрат —
  пять монет, неполная пятёрка видна в следующем квадрате, рядом остаётся точная сумма;
- **цели:** три на выбор в каждой главе, девять всего; строка «хватит ли» под копилкой;
- **рост питомца:** четыре стадии поверх трёх глав «Первый дом», «Холода», «Новый дом» — по отметкам
  заботы, плана и накоплений; переход со строкой причины («Мы ели две недели»); Финни в куртке, с бинтом;
- **события глав:** день рождения Киры, первый снег, новоселье — оба исхода без упрёка; конец игры с
  «Играть дальше» и «Начать сначала»;
- **дневник:** итог прошлой недели, покупки, пройденные задания, цель, словарь из девяти терминов;
- **раздел для взрослого:** чему учит игра, прогресс по заданиям и неделям, сложность, анимации,
  демо, удаление данных;
- **сохранение** после каждого хода; крупный системный шрифт до ×2,0; подписи для экранного диктора.
