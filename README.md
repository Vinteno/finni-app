# Финни

Игра для Android, в которой ребёнок 7–11 лет заботится о питомце Финни и учится обращаться с
деньгами. Каждую игровую неделю приходит доход в монетах. Ребёнок раскладывает его на три
направления — «Нужное», «Хочу», «Копилка», — покупает нужное на неделю, выбирает между вещью и
вещью с надбавкой, копит на цель главы, а в конце недели видит, что задумал и что вышло. Без
оценок: приложение называет факты и никогда не говорит, что выбор был неверным.

Решение задачи 6 трека «Финансы» хакатона ЛЦТ 2026.

**Сборка к сдаче:** [`apk/finni-0.2.0.apk`](apk/finni-0.2.0.apk) · **Документация:** [`docs/`](docs/) ·
**Матрица требований:** [`docs/requirements.md`](docs/requirements.md)

данные, аккаунт не требуется.

## Как поставить APK

1. Скачать `apk/finni-0.2.0.apk` на телефон с Android 8.0 или новее.
2. Открыть файл и разрешить установку из этого источника, если телефон спросит.
3. Запустить «Финни».

Сборка `prototype` оптимизирована как выпускная и подписана отладочным ключом — ставится на
любой телефон без среды разработки.

## Сборка из исходников

Нужны JDK 17 или новее (подходит встроенная в Android Studio) и Android SDK с платформой 36.
Проще всего открыть папку проекта в Android Studio и нажать Run. Из терминала:

```bash
./gradlew :app:assemblePrototype   # оптимизированная сборка → app/build/outputs/apk/prototype/
./gradlew :app:assembleDebug       # отладочная сборка
```

## Проверка

```bash
./gradlew :core:test               # правила: экономика восьми недель, главы, задания, нормы текста
./gradlew :app:testDebugUnitTest   # экраны на JVM, сквозные прогоны и «ребёнок»
./gradlew :app:recordRoborazziDebug  # снимки экранов 360 dp, шрифт ×1 и ×2 → app/build/shots/
```

«Ребёнок» — 80 партий по 300 случайных касаний по всем трём главам; после каждого шага проверяет:
деньги не уходят в минус, числа на экране не больше 100, фразы не длиннее 5 слов, экран не длиннее
25 слов, цели нажатия не меньше 48 dp. Подробно — [`docs/testing.md`](docs/testing.md).

## Демо-режим для проверки

На главном экране — плашка «Взрослым» под кошельком: **удерживать 3 секунды**. В разделе для
взрослого, блок «Демо для проверки»:

- **«Начать демо»** — готовый питомец без предыстории; игра ребёнка сохраняется отдельно;
- **«К неделе…» 1–8** — начало любой недели с состоянием канонического пути: так любое задание и
  любая из трёх стадий доступны сразу, без ожидания;
- **«Сбросить демо»** — к исходному тестовому профилю;
- **«Вернуться к игре ребёнка»** — игра ребёнка как была.

Там же — «Удалить данные игры» (с подтверждением), сложность «Проще / Сложнее», анимации, бонус.

## Устройство

| Модуль | Что внутри |
|---|---|
| `core` | правила игры без Android: модель состояния, ходы недели, расчёты, тексты из состояния, демо-путь. Тестируется на JVM |
| `core/src/main/resources/content/` | контент отдельно от кода: предметы и цели, главы и недели, задания, все тексты |
| `app` | интерфейс на Compose, хранение, питомец и анимации |
| `art/app` | графика: слои Финни, предметы, комнаты |

Экраны ничего не считают сами: каждое действие — ход в правилах `core`, состояние сохраняется после
каждого хода. Новое задание или предмет добавляется в файлы контента — [`docs/architecture.md`](docs/architecture.md).

## Что реализовано

Три главы, восемь игровых недель по каноническому пути (до десяти — при запасных неделях):

- **первый запуск:** предыстория с тремя направлениями, питомец — 3 окраса × 3 аксессуара, имя;
- **главный экран:** Финни, кошелёк, накопления клетками с целью, «Еда», «Чистота», «Тепло», записка
  с текущим шагом; действия — касанием предметов комнаты; касание Финни — подсказка шага;
- **неделя:** доход посылкой, объявление ситуации, план по трём направлениям с остатком и
  превышением, магазин с ценой, категорией и влиянием до покупки, корзина как подтверждение,
  окна нехватки с вариантами и снятие из копилки с отдельным подтверждением, забота дома, взнос,
  итог «Задумали / Вышло» с объяснением разницы и выбором плана следующей недели;
- **ситуации глав 2 и 3:** куртка, заноза, коробка, лампа, угощение, полотенце — две равные карточки
  «вещь» и «вещь с надбавкой» с разложенной ценой;
- **шесть заданий по трём темам:** F1 «Что взять на неделю», F5 «Мячик сейчас или подарок потом»,
  F4 «Сколько отложить», F3 «Куртка уже есть», F2 «Чем заплатить», F6 «Что задумали и что вышло» —
  с объяснением после любого решения;
- **цели:** три на выбор в каждой главе, девять всего; строка «хватит ли» под копилкой;
- **рост питомца:** три стадии — главы «Первый дом», «Холода», «Новый дом» — по отметкам заботы,
  плана и накоплений; переход со строкой причины («Мы ели две недели»); Финни в куртке, с бинтом;
- **события глав:** день рождения Киры, первый снег, новоселье — оба исхода без упрёка; конец игры с
  «Играть дальше» и «Начать сначала»;
- **дневник:** итог прошлой недели, покупки, пройденные задания, цель, словарь из девяти терминов;
- **раздел для взрослого:** чему учит игра, что пройдено, сложность, анимации, бонус 5 монет раз в
  неделю, демо, удаление данных;
- **сохранение** после каждого хода; крупный системный шрифт до ×2,0; подписи для экранного диктора.
