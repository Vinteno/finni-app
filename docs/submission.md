| Package name | `ru.vinteno.finni` |
| Версия | `0.3.2` |
| Номер сборки | `7` |
| Размер | 30 212 268 байт (около 29 МБ) |
| SHA-256 | `f396a6abf2ea4b76b52334b4b3fd7f281fb1f7dc947eee8f519df047777ba269` |
| Подпись | Android Debug, APK Signature Scheme v2 |

Для промежуточной сдачи ТЗ 7.1 требует рабочий APK, но не называет релизную подпись отдельным условием.
Для финальной проверки нужен командный релизный ключ: текущая сборка устанавливается, но подписана
отладочным сертификатом и поверх сборки с другим ключом не обновится.

## Перед ручной загрузкой

- открыть репозиторий и APK в приватном окне без входа;
- установить APK на Android 8.0+ и пройти первый запуск;
- убедиться, что на платформе указана именно версия 0.3.2 (7);
- после любых правок приложения пересобрать APK, повторить тесты и обновить SHA-256 на этой странице;
- не загружать `internal/`, ключ подписи, `local.properties` и другие локальные файлы.

## Что честно остаётся до финала

- проверка на физическом устройстве с ОЗУ от 3 ГБ и замеры запуска/отклика;
- релизная подпись командным ключом;
- презентация, резервное видео и единый PDF/DOCX;
- тексты карточки RuStore и возрастная маркировка;
- пользовательская проверка с детьми — только с согласием законного представителя.
