# «Финни» — реестр графики, шрифтов и библиотек

**Версия 1.0 · 22 сентября 2026**

Заполняется по ходу, а не перед сдачей. Заказчик требует по каждой
сгенерированной картинке указать сервис, модель, что создавали, ссылку на
условия использования и дату. По десятку готовых файлов это задним числом не
восстанавливается. В документацию (пункт 5.12) превратится после прототипа.
