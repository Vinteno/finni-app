# Данные, разрешения, удаление

## Разрешения Android

Приложение **не запрашивает ни одного разрешения**: в `AndroidManifest.xml` нет ни одного
`uses-permission`. Нет доступа к интернету, камере, микрофону, геолокации, контактам, файлам,
Bluetooth.

## Что хранится

| Что | Где | Зачем |
|---|---|---|
| Игровое имя питомца, окрас, аксессуар | `state.json` во внутренней памяти приложения | профиль питомца |
| Сложность, анимации | там же | настройки взрослого |
| Кошелёк, копилка, купленные вещи, глава, неделя, отметки, пройденные задания, история недель | там же | прогресс игры, дневник, раздел взрослого |
| Отложенная игра ребёнка на время демо | `child.json` там же | вернуть игру после демо |

Файлы лежат только на этом телефоне, во внутренней памяти приложения — другие приложения их не
видят. Никуда не отправляются: в приложении нет сетевого кода, сервера, аналитики, рекламы.

## Что не собирается

Имя, возраст, пол ребёнка или родителя, контакты, местоположение, платёжные данные, сведения о
семейном бюджете — не спрашиваются и не хранятся. Имя вводится только питомцу; подсказка к полю —
«Придумай мне имя», и три готовых имени на выбор, чтобы ребёнок не вписал своё (решение I43).
Аккаунта и регистрации нет.

## Как удалить

1. **В игре** — раздел для взрослого (плашка «Взрослым» на главном экране, удерживать 3 секунды) →
   «Удалить данные игры» → «Да, удалить». Удаляются оба файла, игра начинается с первого запуска.
2. **Средствами Android** — Настройки → Приложения → Финни → Хранилище → Очистить данные, или
   удалить приложение.

Удаление и другие действия, заметно меняющие прогресс, требуют подтверждения (ТЗ 3.5, 3.6).
