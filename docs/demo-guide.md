# Проверка демо по Приложению А ТЗ

Демо открывается на главном экране: удерживайте «Взрослым» 3 секунды. До входа игра ребёнка
сохраняется отдельно. «Начать демо» начинает **с первого запуска**: предыстория, выбор внешности,
имя, цель, затем игра. Кнопки «Неделя 1…8» сразу открывают начало соответствующей недели с
состоянием последовательного игрового пути. Кнопки доступны и до включения демо; первое переключение
требует подтверждения. Реального ожидания между неделями нет. Во время знакомства в демо системная
кнопка «Назад» открывает раздел взрослого, чтобы можно было вернуться к игре ребёнка в любой момент.

| Шаги Приложения А | Что показать в приложении |
|---|---|
| 1–3. Первый запуск и профиль | «Начать демо» → предыстория → цвет и аксессуар → игровое имя. Аккаунт и личные данные не нужны. |
| 4. Доход и доступные задания | Выбрать цель, открыть посылку первой недели. Источник и сумма монет показаны; текущее задание указано на записке дома и в дневнике. |
| 5. План | Открыть банки «Нужное / Хочу / Копилка», изменить суммы, показать остаток и подтвердить план. |
| 6. Задание и награда | В магазине недели 1 купить еду и мыло: задание «Покупки на неделю» завершается объяснением, награда показана в копилке и итоге. |
| 7. Два типа покупок и нехватка | Показать еду или мыло как нужное, качели как желаемое. Для окна нехватки отложить на «Нужное» меньше стоимости еды с мылом, подтвердить план и попытаться купить оба предмета; показать варианты до подтверждения покупки. |
| 8. Цель и накопления | На экране цели выбрать один из трёх предметов; после покупки открыть копилку, внести запланированную сумму и показать оставшееся до цели. |
| 9–10. Итог и рост | Закончить неделю: «Задумали / Вышло», показатели Финни и следующий шаг. Пройти следующие недели подряд; после серии решений показать смену стадии и её причину. Для короткого показа открыть неделю 2, затем завершить главу. |
| 11. Сохранение | Закрыть приложение посреди недели, открыть заново и сверить баланс, цель, покупки и прогресс. |
| 12. Взрослый и сброс | Открыть раздел взрослого; «Начать демо заново» возвращает к предыстории. «Вернуться к игре ребёнка» восстанавливает её состояние. «Удалить данные игры» требует отдельного подтверждения и удаляет оба профиля. |

## Прямой доступ к заданиям

| Неделя | Задание или этап |
|---:|---|
| 1 | Покупки на неделю — планирование трат |
| 2 | Мячик или подарок — накопления |
| 3 | Сколько отложить — накопления |
| 4 | Лишняя покупка — покупки |
| 5 | Из каких денег платить — покупки |
| 6 | Лампа — ситуация недели |
| 7 | План и траты — планирование трат |
| 8 | Новоселье — итог главы |

Каждый переход к неделе начинает тестовый участок заново; он не меняет отложенную игру ребёнка.
Для демонстрации ошибочной ветки откройте нужную неделю повторно и выберите другой вариант.
Для непрерывной проверки минимум пяти периодов начните с первого запуска и переходите между
неделями обычной кнопкой игры, без кнопок быстрого перехода.
