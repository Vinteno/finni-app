# Тестирование

Ключевая логика бюджета, списаний, накоплений и прогресса покрыта автотестами (ТЗ 3.4), экраны
проверяются снимками на JVM и автоматическим «ребёнком». Ниже — как запускать, что проверяется,
набор тест-кейсов и отчёт о прогоне.

## Как запустить

```bash
./gradlew :core:test                       # правила: экономика, главы, объяснения, нормы текста
./gradlew :app:testDebugUnitTest           # экраны на JVM (Robolectric): навигация, раскладка, «ребёнок»
./gradlew :app:recordRoborazziDebug        # снимки экранов → app/build/shots/
```

Отчёты после прогона: `app/build/qa/monkey-report.md` (находки «ребёнка»),
`app/build/qa/home-taps.md` (таблица касаний главного экрана).

## Тест-кейсы

Формат: что делаем → что должно выйти. Автотест указан, где кейс проверяется автоматически.

### Экономика

| Кейс | Что делаем → что выходит | Автотест |
|---|---|---|
| E01 | начать игру → после посылки кошелёк 30 | `EconomyTest` |
| E02 | закончить неделю с кошельком ≥ 30 → посылка не приходит, это не ошибка | `EconomyTest` |
| E03 | кошелёк 9 на конце недели 1 → 39 после посылки недели 2 | `EconomyTest` |
| E04 | канонический путь недели 1 → кошелёк 9, копилка 20 | `EconomyTest`, `ChaptersTest` |
| E05 | пройти задание → копилка +10, кошелёк без изменений | `EconomyTest` |
| E06 | задание второй раз → ни монет, ни отметок | `EconomyTest` |

| E08 | 0 в «Нужном» → «Я хочу есть», подтверждение доступно | `ScreensShotTest` |

### Интерфейс

| Кейс | Что проверяем | Автотест |
|---|---|---|
| U01 | зелёного и красного в интерфейсе нет | вычитка снимков |
| U02 | ни одного числа больше 100 | `TextLintTest`, `ChildMonkeyTest` |
| U03 | фраза ≤ 5 слов, экран ≤ 25 слов | `TextLintTest`, `ChildMonkeyTest` |
| U04 | запрещённых слов нет | `TextLintTest`, `ChildMonkeyTest` |
| U05 | база и надбавка анимируются одинаково | одна реакция `доволен` в коде; снимки |
| U06 | ни таймеров, ни мигания, ни зацикленного движения | код; `зябнет` — дрожь ±2 dp с паузой |
| U07 | цели нажатия ≥ 48 dp, текст ≥ 16 sp | `HomeLayoutTest`, `ScreensShotTest`, `ChildMonkeyTest` |
| U08 | «назад» на одном месте и ведёт домой | `FlowTest` |

### Нефункциональное

| Кейс | Что | Как |
|---|---|---|
| N01 | запуск до главного экрана ≤ 5 с | замер на телефоне |
| N02 | отклик ≤ 1 с | замер на телефоне |
| N03 | работа без сети | в приложении нет сетевого кода и разрешения на сеть |
| N04 | закрыть посреди недели 5, открыть — всё на месте | сохранение после каждого хода; проверка на телефоне |
| N05 | нет падений и тупиков | `ChildMonkeyTest`, `EconomyTest` E12 |
| N06 | проверка на физическом устройстве | команда, к финальной сдаче |

## Отчёт о прогоне — 26 сентября 2026

Среда: облачная сборка, JDK 21, Gradle 9.1, Robolectric (Android 15, SDK 35).

- `./gradlew :core:test :app:testDebugUnitTest` — **280 тестов, 0 падений**.
- «Ребёнок»: 80 партий по 300 касаний (20 — с первого запуска, по 20 — с недель 3, 5, 7) —
  **находок нет**: ни минуса, ни убывания отметок, ни трат после итога, ни числа больше 100, ни
  фразы длиннее 5 слов, ни экрана длиннее 25 слов, ни цели нажатия меньше 48 dp, ни падений.
- Снимки всех экранов на 360 × 600 и ×2,0 просмотрены глазами; главный экран глав 1–3 — ещё на
  360 × 800 и 412 × 915. Выборка снимков — `docs/screens/`.

**Проверка на физическом устройстве — выполняет команда, результат будет в финальной сдаче.**
Эмулятор и телефон с ОЗУ от 3 ГБ: полный путь восьми недель с чистых данных, пути «ничего не
покупаю» и «всё в копилку», закрыть посреди недели 5 и открыть, раздел взрослого, замеры N01 и N02.
