# Релизная подпись Android

**Версия 1.0 · 29 сентября 2026**

APK `apk/finni-0.3.2.apk` подписан постоянным ключом команды. Он определяет владельца обновлений
приложения и не восстанавливается после потери. Контрольная сумма сдаваемого файла указана в
`docs/submission.md`.

## До создания ключа

Команда назначает одного владельца ключа и место хранения вне Git-репозитория. Нужны две защищённые
резервные копии у разных участников. Пароль передаётся отдельно от файла и не пишется в чат, Git,
`local.properties`, командную строку или документацию.

## Создание

```bash
scripts/create-release-keystore.sh /абсолютный/путь/finni-release.jks
```

Скрипт не принимает пароль аргументом: `keytool` запрашивает его скрыто. Alias фиксирован:
`finni-release`.

## Сборка и подпись

```bash
export FINNI_KEYSTORE=/абсолютный/путь/finni-release.jks
read -s FINNI_KEYSTORE_PASSWORD && export FINNI_KEYSTORE_PASSWORD
read -s FINNI_KEY_PASSWORD && export FINNI_KEY_PASSWORD
scripts/sign-release-apk.sh
unset FINNI_KEYSTORE_PASSWORD FINNI_KEY_PASSWORD
```

Результат появляется в `build/release/` и не заменяет сдаваемый APK автоматически. Скрипт выравнивает
нативные библиотеки по границе 16 КБ и проверяет подпись. Сначала установить файл на физическое
устройство, пройти сценарий и проверить сертификат; только затем заменить файл в `apk/`, обновить
SHA-256 и документы. Уже установленный прототип с отладочным сертификатом нельзя обновить APK с
другим ключом при том же имени пакета: проверяйте релиз на чистом устройстве либо удалите прототип,
понимая, что локальный прогресс на этом устройстве удалится.

## Что нельзя делать

- не создавать новый ключ для каждой сборки;
- не хранить `.jks`, пароль или файл с паролем в репозитории;
- не менять ключ после первой публичной финальной сборки;
- не удалять старую резервную копию после смены компьютера.
