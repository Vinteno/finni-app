# Разрешения Android, данные и удаление профиля

Пункт 5.9 ТЗ.

## Разрешения

**Приложение не запрашивает ни одного разрешения Android.**

Обязательному сценарию не нужны камера, микрофон, геолокация, контакты и
Bluetooth (ТЗ 3.1.4), а игровой цикл работает без сети (ТЗ 3.1.5). Всё состояние
хранится в приватном хранилище приложения, к которому разрешения не нужны.

| Разрешение | Запрашивается | Зачем |
|---|---|---|
| — | нет | — |

Если разрешение всё же появится, строка добавляется сюда с обоснованием: пункт
3.4 ТЗ требует обосновать каждое.

## Какие данные хранятся

Только локально, на устройстве:

| Что | Зачем | Персональные данные |
|---|---|---|
| Игровое имя ребёнка и имя питомца | обращение в интерфейсе | нет, вымышленные |
| Внешность питомца | отображение | нет |
| Баланс, накопления, выбранная цель, история покупок | игровой цикл | нет |
| Прогресс по заданиям и стадия питомца | игровой цикл | нет |

Аккаунт не создаётся. Возраст, имя, контакты, платёжные данные и сведения о
семейном бюджете не запрашиваются (ТЗ 3.5). Вместо возраста — выбор «попроще или
посложнее».

Данные никуда не передаются: сервера нет, аналитики нет, рекламы нет.
