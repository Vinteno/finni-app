# Тест-кейсы

Пункт 5.10 ТЗ. Ключевая логика бюджета, списаний, накоплений и прогресса
покрывается автотестами либо детально проверяется по этим кейсам (ТЗ 3.4).

Формат: предусловие → шаги → ожидаемый результат. Прогон фиксируется в
[отчёте о проверке на устройстве](device-test-report.md).

## A. Нефункциональные — готовы, от сценария не зависят

| ID | Проверка | Ожидаемый результат | Пункт ТЗ |
|---|---|---|---|
| N1 | Холодный запуск на физическом устройстве, 3 замера | до главного или стартового экрана не более 5 секунд | 3.4 |
| N2 | Нажатие на любой интерактивный элемент | визуальный отклик не более 1 секунды | 3.4 |
| N3 | Режим полёта, полный игровой цикл | цикл проходится целиком, прогресс не теряется | 3.1.5 |
| N4 | Выгрузка приложения из памяти и повторный запуск | профиль, баланс, покупки, накопления, цель и учебный прогресс на месте | 2.5.13 |
| N5 | Сворачивание в середине планирования бюджета | возврат в то же состояние, незавершённый план не потерян | 3.4 |
| N6 | Прогон всего обязательного сценария подряд | нет падений, блокирующих ошибок и тупиковых экранов | 3.4 |
| N7 | Демонстрационный режим: 5 периодов подряд | переходы без ожидания календарных сроков | 2.5.13, 2.6 |
| N8 | Сброс тестового профиля | состояние возвращается к исходному | 2.5.13 |
| N9 | Удаление профиля взрослым | запрос подтверждения, затем состояние первого запуска | 3.5, 3.6 |
| N10 | Системное увеличение шрифта на максимум | текст читается, вёрстка не ломается, кнопки не перекрываются | 3.6 |
| N11 | Скриншоты экранов в градациях серого | ошибка, успех, категория расхода и состояние питомца различимы без цвета | 3.6 |
| N12 | Выключение звука и анимаций в настройках | ничего важного не пропадает, игровой цикл проходится | 3.6 |
| N13 | Экран 360 dp по ширине, портрет | ни один элемент не обрезан, кнопки не меньше 48 dp | 3.1.2 |
| N14 | Установка APK на чистое устройство без среды разработки | устанавливается и запускается | 3.3 |
| N15 | Поиск секретов в истории репозитория | паролей, токенов и ключей подписи нет | 3.4 |
| N16 | Список разрешений в манифесте | пусто либо каждое обосновано в документации | 3.4 |

## B. Игровой цикл — заполняется по сценарию

| ID | Проверка | Ожидаемый результат | Пункт ТЗ |
|---|---|---|---|
| G1 | Распределение больше доступного бюджета | приложение не даёт подтвердить, показывает остаток | 2.5.5 |
| G2 | Покупка при нехватке монет | покупка не проходит, объясняется чего не хватает и какие есть варианты | 2.5.6 |
| G3 | Баланс после любой операции | не уходит в минус ни при какой последовательности действий | 2.5.6 |
